# Data Integration Specialist: Technical Questions and Practical Challenge
Thank you for taking the time to complete this exercise. It includes five brief technical questions followed by a small, practical data-validation challenge. Please spend no more than \*\*60–90 minutes total\*\*. We are interested in your reasoning and judgment, not a production-ready solution.

## Start Here
Read the full \[Technical Questions and Challenge guide](./Data%20Integration%20Specialist%20-%20Technical%20Questions%20and%20Challenge.docx) before beginning.

The supporting data is in the [`files/`](./files/) directory:
- \[`feed\_specification.csv`](./files/feed\_specification.csv): Agreed fields, requirements, formats, and allowed values
- \[`expected\_encounters.csv`](./files/expected\_encounters.csv): The expected synthetic encounter population
- \[`received\_encounters.csv`](./files/received\_encounters.csv): The synthetic feed provided for pre-go-live review

## What to Do
1. Answer the five technical questions in the guide using brief, concrete examples.
2. Compare the received feed with the field specification and expected encounter file.
3. Identify the discrepancies or risks that matter and show enough of your method for someone else to follow your reasoning. You may use SQL, Python, spreadsheet formulas, or another reasonable tool.
4. Recommend whether the feed is ready to proceed, including any fixes or confirmations you would require before go-live.
5. Explain how you would validate a corrected file and what questions you would ask the source team.

## Submission
Submit your written responses along with any queries, scripts, workbooks, formulas, or work notes used in your analysis. Use common, readable formats and include your name in the main response filename. If submitting multiple files, place them in a ZIP archive named with your name.
State any reasonable assumptions you made. If you used an AI assistant, briefly disclose how you used it and how you verified the output. Although the supplied files are synthetic, treat them as confidential production data for this exercise and do not upload or expose the files or their contents to an AI tool.
